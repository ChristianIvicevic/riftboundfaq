# Feedback and Contribution Policy

Riftbound FAQ is independently authored and curated.
Unsolicited content and code contributions are not currently accepted.

## Reporting Issues

Reports of incorrect rulings, outdated references, unclear explanations, and site defects are welcome.

1. Check the existing [issues](https://github.com/ChristianIvicevic/riftboundfaq/issues) to avoid duplicates.
2. Create a new issue with a clear description of the problem or suggestion.
3. Include relevant card names, rule references, page URLs, and supporting sources where possible.

You can also use the feedback controls on any FAQ page or paragraph without a GitHub account.

## Pull Requests

Please do not open a pull request unless the change has been discussed with and requested by the maintainer.
Requested changes must follow the repository's existing content and code conventions and pass its validation checks.

By submitting a requested pull request, you agree that code contributions are licensed under the MIT License and content contributions under `content/` are licensed under CC BY-SA 4.0, and that you have the right to contribute the submitted work.
