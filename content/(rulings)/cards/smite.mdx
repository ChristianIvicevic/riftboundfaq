## Can Guardian Angel, Zhonya's Hourglass, or Tactical Retreat save a unit from Smite? [#death-replacement-effects]

Yes, if the unit's controller applies the protective death replacement before Smite's replacement; if they apply Smite's first, the unit is banished.
All of these effects replace the same death event, so the affected unit's controller chooses their order.<Rule number="372" />

Smite's "if it would die this turn, banish it instead" is a replacement effect.<Rule number="369.1" />
<Card name="Guardian Angel" />, <Card name="Zhonya's Hourglass" />, and <Card name="Tactical Retreat" /> also replace a unit's death.
If the controller applies one of those protective effects first, the kill action does not occur and the unit is healed, exhausted, and recalled.<Rule number="370.1.a.1" />
For the first two effects, the gear also dies in the unit's place.
None of those replacement actions is another death event for the affected unit, so Smite has no qualifying event left to replace.<Rule number="370.1.b" />

If Smite's effect is applied first, it replaces the unit's death with banishment.
Banishment is not a kill,<Rule number="427.2.a" /> so none of the protective effects applies afterward.
