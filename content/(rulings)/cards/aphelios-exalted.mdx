## How does Aphelios, Exalted interact with Svellsongur and Shady Spectacles? [#equipment-copy-effects]

Aphelios triggers once when either <Card name="Svellsongur" /> or <Card name="Shady Spectacles" /> is attached to him, but another unit that becomes a copy of Aphelios through Shady Spectacles does not trigger.

<Callout type="info" title="Earlier Svellsongur ruling">
	The January 2026 [Spiritforged FAQ](https://playriftbound.com/en-us/news/rules-and-releases/riftbound-spiritforged-faq/) ruled that Svellsongur copied Aphelios's ability in time for both instances to trigger.
	The August 2026 [Vendetta FAQ](https://playriftbound.com/en-us/news/rules-and-releases/vendetta-rules-faq-and-clarifications) expressly reverses that ruling because the attachment happens before the copy action.
</Callout>

Each "As this is attached" ability replaces the attachment event with that same event plus a separate copy action.<Rule number="369.1" /><Rule number="370.1.b.1" />
Game actions are processed one at a time, so Aphelios's trigger condition is checked after the attachment event and his ability is added to the chain before the copy action continues.<Rule number="303.1" /><Rule number="383.2.c" /><Rule number="401.1" /><Rule number="401.2" />

With Svellsongur, that pending trigger is created before Svellsongur copies Aphelios's effect text.
The newly copied text does not look back and trigger from the attachment that already occurred, so there is no second trigger.

With Shady Spectacles attached to Aphelios, his trigger is similarly created before he becomes a copy of the chosen unit.
If Shady Spectacles is instead attached to another unit and that unit becomes a copy of Aphelios, the unit did not have Aphelios's ability when the attachment event occurred, so it does not trigger at all.
