## When do I pay 1 energy and return a unit for Emperor's Dais? [#ability-finalization-cost]

During finalization, you decide whether to use the ability<Rule number="383.3.a" /> and, if you do, pay <Energy value={1} /> and return the unit.<Rule number="383.3.b" /><Rule number="383.3.b.1" />
Both actions form one inseparable base cost, so you must complete them together for the ability to finalize.<Rule number="740.4.a" />
The pending ability is removed without finalizing if no legal unit can be chosen<Rule number="402.4" /> or if you decline the complete cost.<Rule number="404.2" />
While paying the energy, you may activate an eligible <Add /> ability with <Reaction /> to provide it.<Rule number="444.2.c" />

The unit you return is part of the cost rather than a target, and it returns to its owner's hand during finalization.<Rule number="355.10.c" /><Rule number="355.10.c.1" />
If you have paid the cost, the ability finalizes and opponents may then react before it resolves.<Rule number="406.2" /><Rule number="406.4" />

<Callout type="warn" title="Errata">
	Emperor's Dais received functional errata.
	Older printings connect the Sand Soldier instruction with "If you do, play"; the current text uses "to play" instead.
	This changes the energy payment and unit return from instructions performed during resolution into one cost completed while finalizing the ability.
</Callout>

## What happens if Emperor's Dais leaves before its ability resolves? [#source-location]

A battlefield token that replaces Emperor's Dais still supplies the "here" location for its Sand Soldier, but if Emperor's Dais leaves without replacement, the Sand Soldier cannot be played because "here" no longer identifies a location.
The replacing token is treated as the same game object as Emperor's Dais.<Rule number="438.1.a" />
Without a replacement, Emperor's Dais has no location when "here" is checked as the instruction executes.<Rule number="359.3.e.12" /><Rule number="359.3.f.1" /><Rule number="359.3.f.2" />
