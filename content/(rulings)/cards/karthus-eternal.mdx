## Does Karthus, Eternal's ability apply if he dies from the same effect as the unit with Deathknell? [#simultaneous-deathknell]

Karthus applies to your other unit's <Deathknell /> if the deaths are simultaneous or that unit is killed before Karthus.
He doesn't apply if a separate kill action kills him first.

When one kill action kills Karthus and another unit simultaneously,<Rule number="370.1.a.2" /> as with <Card name="The Ruination" />, the other unit's <Deathknell /> is added before the kill instruction moves Karthus off the board.<Rule number="428.1.a.1.b" />
His passive ability is therefore still active and makes your <Deathknell /> effect trigger an additional time.<Rule number="365.1" />
If one effect instead performs separate kill actions, those deaths are sequential.<Rule number="370.1.a.2" />
Karthus applies only if the <Deathknell /> unit is killed first, because his passive ability is active only while he remains on the board.<Rule number="365.1" />
When both units instead have lethal damage during a cleanup, all relevant death triggers are added before either unit is killed and moved to the trash.<Rule number="323.4" /><Rule number="323.5" />

## Does a single Not So Fast counter both Deathknell triggers when Karthus, Eternal is on the board? [#countering-dual-deathknells]

No.
If both <Deathknell /> triggers are legal targets for <Card name="Not So Fast" />, one copy can counter only one of them.

When a friendly unit with <Deathknell /> dies while Karthus is on the board, his ability causes that <Deathknell /> to trigger an additional time.
Each trigger is added to the chain as its own independent pending item.<Rule number="808.1.d.2" />
Not So Fast targets a single spell or ability, so each copy can counter only one trigger.

This applies only when the <Deathknell /> ability chooses one of your friendly units or gear.
Otherwise, Not So Fast cannot target either trigger.
