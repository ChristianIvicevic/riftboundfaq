## If Hidden Blade's kill is replaced, does the target's controller draw? [#draw-if-not-killed]

Yes.
The phrase "its controller" links the draw to the unit affected by the preceding kill instruction.<Rule number="359.3.e.14" />
Replacing that kill does not stop the linked draw unless the draw instruction directly refers to the kill action.<Rule number="359.3.e.14.b" />
Hidden Blade refers only to the targeted unit's controller, so that player still draws 2.

<Callout type="idea" title="Example">
	You play Hidden Blade targeting an opponent's unit.
	They respond with <Card name="Zhonya's Hourglass" />, which replaces the unit's death.
	The unit is not killed.
	Because it was still a legal target when Hidden Blade resolved, the opponent draws 2.
</Callout>

## If Hidden Blade's target becomes illegal, does that target's controller draw? [#draw-if-illegal]

No.
An illegal target is unaffected by Hidden Blade, so the kill instruction is ignored.<Rule number="359.3.e.5" />
Hidden Blade's draw is linked to its kill instruction because "its controller" refers to the unit affected by that instruction.<Rule number="359.3.e.14" />
When an earlier linked instruction is ignored, its later linked instructions are also ignored, so the controller does not draw.<Rule number="359.3.e.14.a" />

See [What happens if a target becomes illegal before a spell or ability resolves?](/general-rules/targeting#illegal-targets) for the complete illegal-target procedure.

<Callout type="idea" title="Example">
	You play Hidden Blade targeting an opponent's unit at a battlefield.
	They respond by moving it to their base using <Card name="Flash" />.
	Hidden Blade resolves.
	The unit is no longer at a battlefield, so it is an illegal target.
	The unit is not killed and the opponent does not draw.
</Callout>
