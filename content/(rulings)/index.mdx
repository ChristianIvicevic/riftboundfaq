This is an independently maintained, open-source FAQ to help you learn Riftbound's rules through practical examples and explanations.
Created with input from experienced judges, each page breaks down common questions about rules interactions and gameplay scenarios.

## Using this FAQ [#using]

If you've wondered about how specific card interactions work or when certain game mechanics apply, you're in the right place.
Each page walks through common questions with practical examples and references to the official Core Rules Document, helping you understand not just what the ruling is, but why it works that way.
Rule numbers link to this site's rendering of the official CRD, and card names link to the gallery.
These pages are also handy for sharing in community discussions when the same questions come up.

## About rule references [#rule-references]

Each versioned rulings page shows which Core Rules Document it references, with an "up-to-date" or "outdated" notice at the top.
When a page references an older CRD version, all rule number links point to that specific version until the page gets updated.
Rule numbers and rules text can change between CRD versions.

Remember: the official CRD is always the ultimate authority for Riftbound rules.
This FAQ exists to help you learn through examples and explanations, not to replace the official rules.

## Feedback and corrections [#feedback]

This FAQ is independently authored and curated, but reports of errors and unclear explanations are always useful.
You can provide feedback directly on any page or specific paragraph using the feedback buttons — no GitHub account is needed.
You can also [report an issue on GitHub](https://github.com/ChristianIvicevic/riftboundfaq/issues).
