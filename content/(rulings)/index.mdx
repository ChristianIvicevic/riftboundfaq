Riftbound FAQ is an unofficial, independently maintained, open-source resource.
I'm [Christian “Near” Ivicevic](https://x.com/civicevic), an official Level 2 Riftbound judge, and I created and maintain the project in my spare time to stay current with rules updates and help players and judges understand and verify Riftbound's rules through practical explanations, direct Core Rules citations, and supporting reference material.
Created with input from experienced judges, its rulings break down common rules interactions and gameplay scenarios.

## Using this FAQ [#using]

Riftbound FAQ has three main parts:

- **Rulings** explain common card, mechanic, and general-rules questions through practical examples and direct Core Rules citations.
- The **[Rules Documents](/reference)** section provides unofficial, hyperlinked current and historical Core Rules and Tournament Rules, together with generated comparisons between versions.
- **[Card Errata List](/card-errata-list)** compares printed card text with the current wording you should use.

Use the sidebar or search to find a card, mechanic, general-rules topic, or rules document.
Card names on ruling pages open their Riftbound Wiki pages and show a preview when available.
Rulings are also handy for sharing in community discussions when the same questions come up.
The site deliberately stays focused on rules explanations and supporting references rather than trying to become an all-purpose Riftbound platform.

## About rule references [#rule-references]

Each ruling page shows which Core Rules version it was reviewed against, with an "up-to-date" or "outdated" notice at the top.
When a page references an older version, all rule number links point to that specific version until the page gets updated.
Rule numbers and rules text can change between Core Rules versions.

The reference pages are unofficial renderings generated from Riftbound's published rules documents and may contain parsing errors.
Always use the official Core Rules for gameplay rules and the official Tournament Rules for tournament policy.
This FAQ exists to help you learn through examples and explanations, not to replace the official rules.

## Feedback and corrections [#feedback]

Riftbound FAQ is independently maintained, and reports of errors, unclear explanations, or other suggestions are always useful.
You can send feedback directly through the site in two ways:

- **Page feedback:** At the bottom of every page, select **Good** or **Bad** and leave a message about the page as a whole.
- **Inline feedback:** Highlight or select a text passage to display a floating **Feedback** button, then use it to comment on that specific selection.
